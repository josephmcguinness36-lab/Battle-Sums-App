# **App Name**: Sum It Up

## Core Features:

- User Authentication and Profile Creation: First-time users are prompted to create and save a username, storing user profiles and game progress.
- Challenge Mode Selection: Users select from difficulty levels: Easy, Medium, Difficult (each with sublevels 1, 2, 3), and Expert, influencing the complexity of math problems.
- Free Play Mode Customization: Users can customize settings such as time per sum or number of sums in a row, offering a flexible practice environment.
- Question Generation and Display: Generate mathematical questions tailored to the selected difficulty level and category (addition, subtraction, multiplication, division) and display them clearly to the user.
- Answer Input and Validation: Allow users to input their answers and provide immediate feedback on correctness, updating the game state accordingly.
- Homepage Navigation: Provide a main page with clear options to select game modes and access additional games.
- Game Variety and Selection: Offer access to three distinct mini-games via an icon on the main page to complement the core math challenges.

## Style Guidelines:

- Primary color: Vivid blue (#3498db), to create a sense of trust, logic, and intelligence which makes this a popular and useful color for an educational app. The user feels confident using the game.
- Background color: Light blue (#eaf2ff), for a calm and unobtrusive feel that complements the blue.
- Accent color: Soft lavender (#a9b3f7) to introduce creativity and light that would give the impression of joyfulness and fun
- Body and headline font: 'Inter', a sans-serif font, chosen for a clean, neutral, and modern feel, suitable for both headlines and body text ensuring readability for users of all ages. 
- Use clean and easily recognizable icons for game modes and operations, ensuring clarity for young users.
- Maintain a clean and organized layout, with clear navigation to improve usability.
- Employ subtle animations and transitions to provide feedback, to make the game engaging, and to reward progress.
